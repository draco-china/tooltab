ToolTab uses the unmodified npm browser ES module, bundled into the dedicated
PGP Worker by Vite. Source and build instructions are available in the
upstream README/package.json. To reproduce or replace the library: obtain
source v6.3.1, install its locked development dependencies with npm ci, run
npm run build, and use the resulting dist browser ES module. In ToolTab,
replace the openpgp dependency and rebuild the Vite application and worker.
No OpenPGP.js source modifications are made by ToolTab.
