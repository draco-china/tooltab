PDF editing uses @cantoo/pdf-lib 2.9.1 (MIT, original and Cantoo contributors) and PDF.js 6.3.289 (Apache-2.0, Mozilla Foundation and contributors). Both are unmodified. PDF.js CMaps, standard fonts, WASM decoders and ICC resources are locally distributed under public/pdfjs-6.3.289, with their upstream individual LICENSE files retained. The worker is built from the same pinned package. No runtime CDN is used.

Exact source packages:
- https://registry.npmjs.org/@cantoo/pdf-lib/-/pdf-lib-2.9.1.tgz
- https://registry.npmjs.org/pdfjs-dist/-/pdfjs-dist-6.3.289.tgz
- https://github.com/mozilla/pdf.js/tree/v6.3.289

Library files keep their original licenses; ToolTab's own implementation remains MIT.
